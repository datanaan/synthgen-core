# 三层架构全景

> 类型：topic（跨实体综合分析）
> 编译日期：2026-05-11

## 概述

SynthGen Core 采用三层架构，单向依赖（Interface→Engine→Storage），禁止反向依赖。同层可互相依赖，跨层仅通过抽象接口。

```
┌─────────────────────────────────────────────────┐
│                  接口层 (Interface)               │
│  SynthLang Parser | Type System / Schema DDL     │
│  Python SDK      | REST API                      │
└───────────────────────┬─────────────────────────┘
                        │
┌───────────────────────┴─────────────────────────┐
│                生成引擎层 (Engine)                 │
│  约束分类器 | 执行路由器 | 后筛选保障              │
│  物理引擎   | 数据引擎   | 约束引擎               │
│  EvidencePackage 构建器                          │
└───────────────────────┬─────────────────────────┘
                        │
┌───────────────────────┴─────────────────────────┐
│                存储引擎层 (Storage)                │
│  存储抽象层 (StorageBackend)                      │
│  基表层 | 快照层 | 模型层 | 审计日志              │
└─────────────────────────────────────────────────┘
```

## 各层职责

### 接口层
- [[synthlang]] 解析器：自研 DSL，将用户请求编译为内部语法树
- 类型系统 / Schema DDL：类型是一等公民，ORDER 声明排序列
- Python SDK / REST API：用户唯一直接交互的接口

### 生成引擎层
- [[constraint-classifier]]：编译阶段分类约束类型
- [[execution-router]]：根据约束完备性和数据充足性选择生成路径
- [[physics-engine]]：物理驱动（矩形域采样→拒绝采样/MCMC）
- [[data-engine]]：数据驱动（KDE 密度估计）
- [[post-filter]]：约束驱动（后筛选保障）
- [[tail-report]] + [[evidence-package]] 构建器

### 存储引擎层
- [[storage-engine]]：StorageBackend 抽象接口
- 基表层（INSERT ONLY）→ 快照层（不可变）→ 模型层（版本链+GC）→ 审计日志（哈希链）
