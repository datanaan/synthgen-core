# 版本路线图与依赖关系

> 类型：topic（跨实体综合分析）
> 编译日期：2026-05-11

## 概述

能力里程碑方法论：按"系统能做什么"划分版本，每个版本交付可演示的产品能力。三线并行：明线（功能）、暗线（脚手架）、工具线（开发辅助）。总计 31 功能 + 14 脚手架 + 6 工具 = 51 组件，29-33 周。

## 四个版本

### v1 最小可运行（8.5-9.5周）
**产品故事**：定义数据域→导入真实数据→矩形域物理采样→值域验证→证据包

核心组件：Parser(#1) → 类型系统(#2) → 数据导入(#3) + 基础存储(#4) → 物理引擎v1(#5) → 值域验证(#6) → tail_report(#7) → EvidencePackage v1(#8) → SDK/REST(#9)

关键限制：仅矩形域采样，无数据驱动，无漂移检测，审计不可变 not_applicable

### v2 约束完整（12-13周）
**产品故事**：三类约束+数据引擎+5条退化路径+后筛选+审计

核心组件：行间引擎(#10) → 聚合引擎(#11) + 约束分类器(#12) → **执行路由器重构(#13)** + 数据引擎KDE(#15b) → 后筛选(#14) + DURING/WHEN(#16) → EvidencePackage v2(#17)

**关键重构**：v1 硬编码调度 → v2 多路径路由器（2周重构），类比自行车改摩托车

### v3 时间智能（6-7周）
**产品故事**：模型进化、时间旅行、持续对齐

核心组件：模型版本链(#18) → GC compaction(#19) → 时间旅行AS OF(#20) + 持续对齐(#21) → tail_report增强(#22) + 存储模型层(#23) + 偏差报告(#24)

### v4 高级分析（4-5周）
**产品故事**：窗口全面扩展、完备度连续化

核心组件：行数窗口(#25) + 分组窗口(#26) → 会话窗口(#27) + 完备度评分(#28) + 反例搜索(#29, research) → EvidencePackage v3(#30)
