# SynthGen Core

> 类型：项目
> 首次编译：2026-05-11

## 定义

面向物理世界的智能合成数据生成器。以生成原生数据库内核架构构建，在用户给定的数据世界框架内，生成物理合法、统计逼真、完全可追溯的合成数据。当前处于规格文档阶段。

## 详情

**使命**：在用户给定的数据世界框架内，生成其可能存在样貌的多样性。

**系统边界**：
- 负责：在已知物理边界和用户输入格式内，生产可追溯的候选数据集
- 不负责：判定所生成数据的最终可信性；不替代高保真物理仿真器或 ML 训练平台

**产品形态**：以生成为核心的融合型基础设施。借鉴数据库内核方法论（声明式解析、优化器、存储抽象、审计日志），用户购买的是系统软件。

**最终理论公式**：
格式忠实性保证 + 统计签名条件保证 + 物理合法性优先 + 约束类型分层 + 认识论偏差声明 + 可追溯性保证 + 持续对齐能力 + 组合退化降级体系 + 身份切换与服务分级

**用户接口**：
- Python SDK（`pip install synthgen`）— 面向数据工程师/ML工程师
- REST API — 面向 ISV、应用集成方
- SynthLang 为内部编译目标，v1 不直接对用户暴露

**团队**：4-6 人专业数据库团队，C/C++/Rust 技术栈，总工期 29-33 周。
