# 开发辅助工具（工具线）

> 类型：工具
> 首次编译：2026-05-11

## 定义

开发过程中的辅助工具，不产生最终交付物，但加速组件开发、测试编写、接口一致性检查和故障诊断。不写产品核心逻辑。

## 详情

**四个工具**：

| 工具 | 实际技术 | 需要AI | 诚实命名 |
|------|---------|-------|---------|
| 组件模板引擎 | inja(C++) 或 Jinja2(Python) 模板展开 | 不需要 | 非"Agent" |
| 测试辅助库 | C++ 头文件库 + 测试宏 | 不需要 | 非"Agent" |
| Schema 一致性校验器 | Python 结构化 diff + 字段比对 | 不需要 | 非"Agent" |
| Trace 分析工具 | Python 规则引擎，AI 可选增强 | 部分需要 | 部分"Agent" |

**四条原则**：
1. 先建后用——工具依赖已完成组件的惯例，不能先于惯例存在
2. 不写产品代码——核心逻辑必须人写
3. 产出必须可验证——骨架能编译通过、测试宏能在标准数据集上通过
4. 工具也是软件——模板/规则随接口变化需维护

**v1 引入时间线**：
- 第 1-3 周：工具线空白期（无模板素材）
- 第 4-5 周：从 #5/#6 提炼模板 → 生成 #8 骨架
- 第 6-7 周：测试辅助库（需测试框架和标准数据集就位）
