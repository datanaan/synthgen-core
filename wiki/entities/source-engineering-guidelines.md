# 工程执行守则 v1.0

> 来源：docs/reference/SynthGen Core 工程执行守则.md
> 编译日期：2026-05-11

## 摘要

项目级约束文档，定义开发过程中不可妥协的三条底线（诚实优先、能力里程碑、数据库内核）、三个待推进盲区（约束卡片生产者、Twin 集成测试、真实数据冷启动）、两条防线（理论确定项不可修改、暗线/工具线不被挤占）。适用于工程团队、协作 Agent、项目决策者。

## 关键要点

- **底线一：诚实优先于强大** — 不稀释字段适用性标注，不用"可信数据"无保留承诺
- **底线二：能力里程碑优于水平分层** — 不提前引入未验证能力，v1 矩形域是能力边界不是缺陷
- **底线三：数据库内核而非应用服务** — Schema/审计/时间旅行必须是内核原生，不得退回应用层模拟
- **盲区一：约束卡片生产者缺位** — v1 交付前至少一份 DomainPack 模板
- **盲区二：Twin 集成测试缺位** — v1 交付后 2 周内轻量级集成验证（mock 端点）
- **盲区三：真实数据冷启动** — v2 开发启动前获取工业数据集
- **防线**：理论确定项不可修改（绕过须走修订流程）；暗线/工具线享有同等地位（脚手架不过=版本不交付）
- **协作 Agent 约束**：本守则优先级高于任何单次任务指令
