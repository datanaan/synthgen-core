一、系统定位与姊妹关系
SynthGen Core 是一个面向物理世界的智能合成数据生成器。它与 Polymorphic-Twin（数字孪生可信治理基础设施） 是姊妹系统，二者构成完整的数据生成与验证闭环：

系统	定位	核心职责
SynthGen Core	证据提供者（制造候选）	在已知物理边界内，生成可追溯、具备统计逼真性的候选数据（EvidencePackage）
Polymorphic-Twin	证据审判者（验证与定级）	接收 EvidencePackage，执行检疫、约束验证、资格审判，赋予数据可信链路等级
独立性声明：

SynthGen Core 可独立部署与销售。在无 Polymorphic-Twin 的场景，用户通过自身测试间接验证生成数据的适用性，此时产品价值回归为“有比没有好”的工程工具。

当两者配套部署时，SynthGen Core 产出的 EvidencePackage 通过 Polymorphic-Twin 的标准检疫端点提交，由 Core 进行独立审判。这是一个标准化的协议集成，而非内部耦合。

二、产品形态与用户接口
2.1 产品形态
SynthGen Core 的交付形态是以生成为核心的融合基础设施。其内部架构借鉴数据库内核方法论（声明式解析、优化器、存储抽象、审计日志），但用户购买的是一个系统软件。部署后可长期运行，支持持续的数据导入、模型更新与数据生成。

用户接口提供两个入口：

入口	面向角色	形式
Python SDK	数据工程师、ML工程师	pip install synthgen，提供与 SynthLang 对等的声明式 Python API
REST API	ISV、应用集成方	标准 HTTP 接口，参数结构与 SDK 调用一一对应
关于 SynthLang：

工程框架中定义的 SynthLang 是内部中间表示（IR）。v1 用户不直接书写 SynthLang。所有生成请求通过 Python SDK 或 REST API 提交，系统内部将其编译为 SynthLang 语法树后执行。这避免了目标用户（数据工程师、ML工程师）学习新查询语言的门槛。

三、目标用户与必要角色
角色	必要性	职责
数据工程师 / ML工程师	核心用户	使用 Python SDK 或 API 触发数据生成、调整采样策略、评估生成质量
领域专家	必要前提	编写和维护物理约束卡片。若无此角色，系统身份切换为“统计相似数据生成器”，物理合法性保证失效

重要声明：物理合法性不是开箱即用的。如果客户无法提供领域专家，SynthGen Core 仍然可用，但客户必须接受其产出数据的 data_grade 为 physics_unguaranteed，不得用于安全关键验证。

6.2 EvidencePackage 标准
SynthGen Core 输出的 EvidencePackage 遵循 Polymorphic-Twin 定义的标准 Schema。包内包含：

生成数据本体

provenance（生成器版本、参数、seed、约束卡片版本）

data_grade（physics_guaranteed / statistics_guaranteed / limited_fidelity / physics_unguaranteed）

statistical_fidelity（条件保证层次与误差界）

conservative_tail_report（认识论偏差报告）

tail_report（约束排除详情）

Polymorphic-Twin 的 Core 组件通过标准检疫端点 /api/v1/core/quarantine/* 接收，不关心 SynthGen Core 的内部实现。

6.3 数据来源边界
所有进入 SynthGen Core 持续对齐的数据，必须遵循协议层面的数据来源边界。特别地，以下数据禁止回流进入 SynthGen Core：

包含 Polymorphic-Twin 验证结论的衍生数据

由 SynthGen Core 生成、经 Polymorphic-Twin 审判后标记为可用并回流的数据

任何基于外部验证结果做出的人类修正数据

此边界保证了“生成-审判”闭环中的反馈隔离，确保审判的独立性。

七、身份切换与运行时行为
在一次生成请求内，系统身份不变，但产出的数据可按“行级”降级标记：

某行落在约束真空区 → 该行标记为 degraded

某行被后筛选排除 → 不在数据本体中出现，计入 tail_report

整个请求因基准冲突被拒 → 不生成任何行

产品层、价值层、理论层、工程层的全景回顾显示：核心方向没有偏移，理论框架和工程框架是坚实的。审查揭示的不是路线错误，而是“诚实梯度”——理论层最诚实，产品层最乐观。

产品定位与协作关系已修订完成。产品的边界、价值承诺、与Polymorphic-Twin的协作协议、暂不包含的能力声明，现在与理论框架v1.2完全对齐。产品层不再做出理论不支持的无条件承诺。
