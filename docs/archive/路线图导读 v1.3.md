路线图导读 v1.3
版本：v1.3
对应路线图：SynthGen Core 开发路线图 v1.3

一、这份文档是什么

路线图 v1.3 是 v1.2 与脚手架工程建议书的合并版。

v1.2 是明线——31个功能组件，4个版本，25-29周。
脚手架工程是暗线——14个脚手架组件，与功能组件同版本交付。

v1.3 把两条线织成一份文档：每个版本同时包含功能组件清单（明线）和脚手架组件清单（暗线），每个版本同时包含功能验收标准和脚手架验收标准。

二、v1.0 → v1.1 → v1.2 → v1.3 的演化

版本	核心变化
v1.0	初版：4版本、31组件、21-25周
v1.1	诚实性修复：字段适用性、反例搜索研究性标记、审计不可变声明、ORDER预留
v1.2	数据引擎落地：#15b数据引擎v1(KDE)进入v2、物理引擎限定矩形域、tail_report修正述
v1.3	暗线合入：脚手架工程(Explain/Trace/可观测性/测试/CI/错误注入)嵌入每个版本，v3增加待测模型接入协议验收标准，总估算28-32周
