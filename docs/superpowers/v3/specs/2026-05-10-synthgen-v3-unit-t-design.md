## 一、本 Unit 交付什么

1. **#22 tail_report 增强版**（1w）：排除率与 data_grade 联动 + fidelity_mismatch + 代偿模型状态

## 二、#22 tail_report 增强版

### 2.1 核心语义

将 v2 已有的误差界数据增强呈现到 tail_report 中。**注意：误差界数据在 v2 的 statistical_fidelity 中已有，此处是呈现增强，非新增计算。**

### 2.2 新增字段

- 排除率与 data_grade 联动
- fidelity_mismatch 标记
- 代偿模型状态

（接口定义见 v3 阶段设计规范 3.5 节）

### 2.3 验收标准

- [ ] 排除率与 data_grade 联动呈现正确
- [ ] fidelity_mismatch 在 compaction 退化时标记
- [ ] 代偿模型状态正确呈现

---

## 三、#23 存储模型层

### 3.1 核心语义

存储模型层提供检查点存储、流式加载和原子写入事务。

**atomic_write 事务**（两阶段提交）：
1. 写数据（临时文件）
2. 写元数据（版本链注册）
3. 提交审计（审计日志记录）
- 中断恢复以元数据层状态为准

（接口定义见 v3 阶段设计规范 3.6 节）

### 3.2 验收标准

- [ ] 检查点存储正确
- [ ] 流式加载正确
- [ ] atomic_write 事务：中断恢复以元数据层状态为准
- [ ] 版本索引正确

---

## 四、#24 偏差报告

### 4.1 核心语义

偏差报告记录 compaction 退化时的偏差信息，证明链可重建。

（接口定义见 v3 阶段设计规范 3.7 节）

### 4.2 验收标准

- [ ] 偏差报告字段完整
- [ ] 证明链可重建
- [ ] version_mismatch 标记正确
